## 3. 全站统一规则

- 每章标题继续使用问题或叙事句，不以方法名作主标题。
- 每章默认可见的解释优先控制在 1–3 个短段落；完整边界进入统一的“查看研究细节”。
- 同一概念首次出现时用人话：
  - 传播 → `晚点继续往下传`；
  - 恢复/吸收 → `晚点被后面的航班追回`；
  - episode → 中文访客层统一为 `连续延误段`；
  - censored → `观察中断 / 尚未看到最终结果`；
  - sample / n → `次航班衔接 / 次观察`。
- 原始技术词可在研究细节或英文方法语境保留，但不能作为中文默认主卡标题。
- 每章最多固定显示一句白话边界；完整限制在研究细节和第 08 章收口。
- 统一使用原生 `<details>/<summary>`，中文 `查看研究细节`，英文 `View research details`；可按章增加更具体的 summary，但禁止层层嵌套。
- 不依赖 hover 才能访问关键信息。

## 4. 第 06 章补充修正

在已验收结构上补清两个核心概念，不能重新扩成长页面：

### 4.1 三把尺子的意义

默认可见的 30/60/90 说明改为：

- 它们是围绕同一个计划起飞时刻的三种**总统计范围**；
- 30 分钟 = 前 15 + 后 15；60 = 前 30 + 后 30；90 = 前 45 + 后 45；
- 短窗口更敏感，长窗口更平滑；60 是主口径，30/90 用来检查换一把尺子后主要方向是否仍存在；
- 不把三档包装成三个同等重要的主要结论，也不说它们是延误持续时间。

### 4.2 机场只和自己比较

必须默认可见一句：

> 排班松紧是在每个机场内部比较：一个时刻只和这个机场自己的通常水平相比，不把大型枢纽和小机场直接比航班数量。

研究细节可补充：在每个机场内部按相对百分位分为约 25% 低、50% 中、25% 高；由于并列值，最终样本不会严格等于 25/50/25。不得把低/中/高写成永久的机场类别，它分类的是“某机场的某个时刻/航班衔接”。
