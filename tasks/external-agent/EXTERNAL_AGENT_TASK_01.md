# External Agent Task 01 — V0.5 首屏「网络呼吸」原型

## 任务目标

只重做网站首屏，把当前偏静态、偏传统的首屏升级为一个有真实数据含义的航空网络现场：机场节点随压力呼吸，轮转路径上的信号持续移动，日期播放会改变整张网络的紧张程度。

视觉方向参考 Flight Path 的现代实时感，但不复制其界面；本项目仍保持自己的墨黑、薄荷绿、琥珀色和红色语义。

## 本轮范围

- 新增独立的 `NetworkHero` 客户端组件，并接入现有首页首屏。
- 使用 Canvas 2D 或同等轻量方案实现美国本土网络背景、机场节点、弧线路径和移动粒子。
- 加入 2026 年 5 月 1—31 日的播放/暂停与日期拖动控件。
- 使用 `v0-data.json` 中的真实月度机场指标、每日全国指标和 4 个真实轮转故事驱动视觉。
- 保留中文优先与中英切换；控件、说明、ARIA 文案均须双语同步。
- 保留现有页头导航、首屏关键数字和进入机场榜/轮转故事的入口。
- 桌面端要有沉浸感，手机端允许简化粒子与标签，但不能退化成一张静态图。

## 数据诚实边界

- 不得伪造“逐日逐机场流量”。现有逐日数据是全国层面，只能用于控制全局网络强度和当天 HUD 数字。
- 节点大小/基础呼吸强度来自机场月度 `pressureScore`、`delayRate` 或 `propagationRate`。
- 飞行弧线只来自 `stories[].legs` 中实际存在的起讫机场，不生成虚构航线。
- 机场位置必须来自明确、可复核的经纬度或静态坐标表；不得用哈希、随机数或视觉散点冒充地理位置。
- 弧线颜色遵循航段状态：延误/传播使用琥珀或红色，吸收/恢复使用薄荷绿。
- 视觉说明应明确这是“代表性轮转链路 + 全国每日压力”，不是全美所有航班的实时轨迹。

## 首屏构成

1. 全屏或接近全屏的深色航空网络画布。
2. 左侧主叙事：项目名、核心问题、549,388 条轮转关联，以及两个跳转入口。
3. 底部 HUD：当前日期、当日延误率、取消率、传播率、播放按钮和 31 日时间轴。
4. 右侧/画布内只标注少量关键机场；悬停或点按节点时展示机场代码与压力指标。
5. 轻微空间漂移、扫描或景深可以使用，但不能造成眩晕或遮挡数据。

## 动效要求

- 使用 `requestAnimationFrame`，正确处理 resize、devicePixelRatio 和组件卸载。
- 呼吸幅度必须映射数据，不使用每个节点完全一致的随机 CSS pulse。
- 日期变化必须可感知地改变节点或网络整体强度，而不只是更新 HUD 数字。
- 粒子沿二次贝塞尔弧线移动；路径状态决定颜色与速度范围。
- 尊重 `prefers-reduced-motion`：停止自动播放和持续位移，保留可读的静态网络；控件状态不能显示为仍在播放。
- 后台标签页不可持续进行高成本绘制。
- 避免为这个原型引入需要 API key 的地图服务或外部运行时请求。

## 明确不做

- 不重写机场榜、航司比较、轮转故事和方法论等后续区域。
- 不修改 Python 数据审计和生成管线。
- 不把项目改成 3D 地球，也不增加登录、数据库或实时 API。
- 不发布、不提交 Git；先交付本地可看的原型。

## 验收标准

- 首屏第一眼能看到“网络正在承受并传递压力”，不是装饰性背景。
- 日期播放时 HUD 与网络强度同步变化。
- 机场和航线均能追溯到现有数据，说明不过度声称。
- 中文、英文、桌面和手机布局均可用，键盘可操作。
- `npm.cmd test` 通过，控制台无持续报错或动画资源泄漏。
- 改动尽量集中在新增组件、首屏接入和对应样式，不破坏后半页。

### 必须修正

1. **不得使用伪造机场位置。** 当前 `hashPosition()` 为缺坐标机场生成散点位置。Top 42 机场中有 23 个使用该逻辑；真实轮转故事中的 LAX、SMF 也使用该逻辑。应改为项目内可复核的静态机场经纬度/投影坐标表，并注明数据来源；未取得坐标的机场宁可不显示，也不能伪装成地理位置。
2. **日期必须真正驱动网络呼吸。** 当前日期只明显更新 HUD，并轻微改变弧线透明度；节点半径仅由月度 `pressureScore` 和时间正弦波决定。应让全国每日压力以明确但不误导的方式调节整网节点光晕、呼吸幅度或背景能量，并保持说明为全国层面信号。
3. **补足美国本土的空间语境。** 当前画布主要是矩形网格和 WEST/EAST 标签，没有任务书要求的美国本土轮廓或等价的可信地理底图。可使用代码绘制的简化边界/项目内静态 GeoJSON，不使用需要 key 的地图服务。
4. **修正 reduced-motion 控件状态。** 当系统启用 reduced motion 后，用户仍可点击播放并看到“暂停/playing”状态，但日期不会推进。应禁用自动播放或让按钮保持非播放状态并给出正确说明。
5. **ARIA 完整双语化。** 中文机场按钮的可访问名称中仍出现英文 `pressure`，需使用中文“压力指数”；英文保持英文。

### 最终通过前必须完成

1. **坐标来源仍不可复核。** 当前代码只写了 `compiled from FAA airport identifiers and approximate airport coordinates`，任务记录只写“按 FAA/IATA 整理”。FAA/IATA 机场代码不是坐标数据来源，也没有给出具体数据集、URL、原始经纬度或可复现的投影方法。请补充一个明确来源，并优先把源经纬度以独立静态数据文件保存，再由统一投影函数转换为画布坐标；不要只保留手工归一化结果。
2. **低动态模式的禁用状态不是 React 状态。** `disabled={stateRef.current.reduced}` 读取的是 ref；`matchMedia` 变化只修改 ref，并不保证组件重新渲染。首次载入且系统已开启 reduced motion 时，按钮可能外观仍为可用，点击后却无响应。请增加 `reducedMotion` state，由监听器更新它，并用该 state 控制 `disabled`、播放状态和可访问说明。
